STUDY PLAN EXAM DATE/TIME - ADMIN ONLY  (one-time Firestore rules addition)
===========================================================================
Exam date/time is stored in Firestore document  config/planner.
Everyone signed-in can READ it; only admins can WRITE it.

In Firebase Console > Firestore Database > Rules, add this block INSIDE your existing
"match /databases/{database}/documents { ... }" and keep all your current rules:

    match /config/{docId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
        && request.auth.token.email.lower() in [
          'akshat.y.shah1725@gmail.com',
          'yateseducationaccaresource@gmail.com'
        ];
    }

(If your rules already have an isAdmin() function, use:  allow write: if isAdmin();)
Click Publish. Then open admin.html > "Study plan" > set date & time > Save.
