ACCA EXAM PRACTICE — ACCOUNT / CLOUD SAVE SETUP

Important
The updated HTML now includes an account panel with Sign in, Create account, Reset password, and cloud-save integration. Real cross-device accounts require a Firebase project. The account feature is not active until the Firebase Web App config is added and Firebase services/rules are configured.

1) Create/open a Firebase project
- Open https://console.firebase.google.com/
- Create a project (or select your existing project).
- Go to Project settings (gear icon) > General > Your apps.
- Add a Web app (</>) if one does not exist.
- Copy the Firebase Web App config object. It contains apiKey, authDomain, projectId, appId (and possibly other fields). This web config is not a password; do NOT share service-account private keys.

2) Enable email/password accounts
- Firebase Console > Build > Authentication > Get started.
- Sign-in method > Email/Password > Enable > Save.

3) Create Firestore database
- Firebase Console > Build > Firestore Database > Create database.
- Use production mode if available, then apply the rules below.

4) Firestore security rules
Publish these rules. They ensure each signed-in user can read/write only their own progress document:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/aaStudyHubProgress/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

5) Connect the HTML
- Open AA_Exam_Practice.html in a browser using HTTPS hosting (e.g. your own site/GitHub Pages). Firebase sign-in modules may not work reliably when opened as a local file.
- Click Account / Cloud Save.
- Paste the Firebase Web App config as JSON into the config box and click Connect Firebase.
- Create an account using your email and a password of at least 6 characters.
- Repeat the config step on every new device until the same Firebase config is embedded in the hosted HTML file.
- Sign in with the same account on another device. Saved progress should be restored from Firestore.

6) Before using with real users
- In Firebase Authentication settings, configure authorized domains for your hosted website.
- Verify the published Firestore rules are active. Never use open rules such as allow read, write: if true.
- Keep a backup of the original AA_Exam_Practice.html before replacing your hosted file.

Notes
- This feature syncs the app's practice state (answers, flags, sessions, question history, written practice, settings and scores) to a per-user Firestore document when the app's save() function runs.
- This account feature has not been connected to a Firebase project because no project configuration was supplied with the files. Do not treat account creation/cloud sync as live until configured and tested.
